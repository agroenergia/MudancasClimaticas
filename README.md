# Mudanças Climáticas

Site experimental sobre mudanças climáticas, criado com a mesma arquitetura organizada utilizada no projeto PPGAD/UFT.

## Primeira versão

A página inicial apresenta **Alô Mundo** como demonstração e já possui:

- layout responsivo;
- cabeçalho e navegação;
- CSS separado do HTML;
- JavaScript separado;
- estrutura preparada para GitHub Pages;
- adaptação para computador, tablet e celular.

## Estrutura

```
MudancasClimaticas/
├── index.html
├── assets/
│   ├── css/style.css
│   └── js/app.js
└── README.md
```

## Desenvolvimento

Fluxo recomendado:

1. analisar a estrutura atual;
2. planejar a alteração;
3. modificar somente os arquivos necessários;
4. testar em desktop, tablet e celular;
5. documentar;
6. criar um commit com mensagem clara.

## Publicação

O projeto pode ser publicado pelo GitHub Pages a partir da configuração do repositório.

Projeto experimental — primeira versão.
